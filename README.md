# Оно тебе надо

Учебная работа Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/shimoro3212/ono-tebe-nado-ad

Семантическая разметка, сетки Grid и Flexbox, локальные шрифты, фоновые изображения и оверлеи. Страница рассчитана на ширину 1100 пикселей в соответствии с макетом.

Для просмотра откройте `index.html` в браузере.
